# STR Serviços Domésticos

## Diretrizes técnicas

- Repositório: strsitemas/STR--Servicos
- Desenvolvimento exclusivamente no terminal Linux.
- Arquivos e scripts produzidos via heredoc EOF.
- Next.js, React, TypeScript e Tailwind CSS.
- Interface: shadcn/ui.
- Banco planejado: Neon PostgreSQL.
- ORM planejado: Prisma.
- Hospedagem planejada: Vercel.
- Pagamentos planejados: Stripe Connect.
- Testes unitários, integração e E2E obrigatórios.
- Documentação e evidências automatizadas.
- Nenhum segredo em repositório Git.
- Produção protegida e separada de homologação.

## Regra de negócio fundamental

A STR atua exclusivamente como intermediadora
tecnológica de serviços domésticos.

Não deverá exercer direção ou subordinação
sobre os profissionais independentes.

As relações contratuais e os controles da
plataforma exigem validação jurídica.
