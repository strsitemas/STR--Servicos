# STR 028 — Catálogo público

## Escopo

Implementação inicial somente leitura.

- `GET /api/catalogo`
- Página `/servicos`
- Filtro por categoria de serviço
- Listagem de profissionais aprovados e ativos

## Critérios de exposição

A API só consulta profissionais com:
- `ativo = TRUE`
- `status_validacao = 'APROVADO'`
- serviço relacionado ativo

Os dados retornados são limitados a:
- identificadores técnicos
- nome de exibição
- cidade e UF
- categoria de serviço

Não retorna CPF, telefone, e-mail, documentos
ou informações de pagamento.

## Segurança

- Consultas SQL somente leitura
- Nenhuma operação de cadastro público
- Nenhuma migration nesta etapa
- Nenhuma alteração intencional em Production
- Sem Stripe
- Endpoint limitado ao Preview com branch esperada
- Erros internos não são enviados ao cliente
- Cache HTTP desabilitado

## Limitações

O catálogo é inicial e não possui paginação completa.
A interface utiliza o estado vazio quando não há
dados cadastrados. O limite das consultas não deve
ser confundido com contagem total de registros.

O modelo de intermediação não estabelece,
por si só, inexistência de vínculo empregatício;
a operação deverá respeitar as condições jurídicas reais.

## Homologação

Build, lint e consultas remotas deverão ser
registrados antes da conclusão da etapa.
