# STR 029 — API administrativa de categorias

## Escopo

- GET /api/admin/servicos
- POST /api/admin/servicos
- Validação de nome e descrição
- Consulta e inserção parametrizadas no Neon
- Bloqueio de acesso administrativo não autorizado

## Segurança

O acesso exige, simultaneamente:
- Vercel Preview
- Branch Neon homologacao
- Token administrativo de alta entropia
- Cabeçalho Authorization Bearer válido

A variável STR_ADMIN_API_TOKEN não será criada
nesta etapa. Assim, as operações permanecem
indisponíveis no deployment inicial.

Nenhuma credencial deve ser exposta ao navegador,
incluída no Git ou colocada em uma variável NEXT_PUBLIC.

Este token será apenas uma credencial técnica
temporária para operações administrativas via servidor
ou ferramenta interna; não substitui autenticação
de usuários, RBAC, auditoria e controle de sessões.

## Regras de banco

- Não executa migrations
- Não altera schema
- Nenhuma operação DELETE ou UPDATE
- Não cadastra dados reais nesta etapa
- Não utiliza Neon Production

## Critério de homologação

- Testes de validação aprovados
- TypeScript, ESLint e build aprovados
- Preview Ready
- Requisições sem token bloqueadas remotamente

## Pendências

- Provisionamento controlado do token
- Autenticação administrativa com identidade
- RBAC e auditoria de gravações
- Testes de integração autenticados
- Proteção de abuso e limites operacionais
